# Резервная копия коллекции

В настройках выберите «Экспорт в JSON» и сохраните файл. Для переноса выберите
«Импорт из JSON» на другом устройстве.

Формат v2 сохраняет доски, ссылки, исходный текст, метаданные, ИИ-описания,
источники анализа, теги, заметки, даты создания/открытия, отметки «Попробовать»,
«Готово», «Не важно», историю напоминаний и даты будущих индивидуальных напоминаний.
Импорт принимает также старые форматы v1 с именами приложения `pinbox` и `polka`.

Импорт объединяет коллекции: доски сопоставляются по имени, существующие ссылки
пропускаются вместе с их отметками и напоминаниями. Повторный импорт не меняет
существующие посты. Новые посты записываются одной транзакцией; если запись
прерывается ошибкой, эта партия постов откатывается. Созданные перед ней доски
могут остаться пустыми.

Индивидуальные напоминания восстанавливаются после записи постов и привязываются
к их новым идентификаторам. Прошедшие даты не планируются. Если система запрещает
уведомления или отклоняет планирование, импорт сохраняет посты и показывает число
невосстановленных напоминаний. Их можно задать повторно в карточках постов.
Автоматическое возвращение к старым постам использует настройки нового устройства.

JSON не содержит файлы скриншотов и локальный кэш картинок: переносит только ссылки
на изображения. Он также не содержит ключи API, Instagram-сессию и настройки
устройства. Для переноса локальных изображений нужен отдельный формат с вложениями.

Проверка логики переноса: `npx tsx --test tests/backup.test.ts` (Node 22.13+).
Тест использует настоящую SQLite, заменяя нативный выбор файлов и планировщик
уведомлений. Системный диалог разрешений и фактическую доставку следует проверять
на устройстве: экспорт → импорт → открытие поста по напоминанию, отдельно с
разрешёнными и запрещёнными уведомлениями.
