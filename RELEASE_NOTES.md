# Grabbit 1.7.0

- Вход в Instagram теперь необязательный и нужен только для закрытых постов. Публичные посты читаются без входа, при первом запуске вход не предлагается.
- Перед входом приложение честно объясняет, как это работает: вход идёт на официальной странице instagram.com внутри приложения, пароль мы не видим, cookie хранятся только на телефоне.
- Если пост не удалось прочитать, на его экране есть кнопки «Войти, чтобы читать закрытые посты» и «Поделиться скриншотом».
- Скриншоты можно отправлять в Grabbit через «Поделиться». ИИ разберёт пост по картинке и прикрепит её к новому посту или к последнему закрытому.
- В настройках видно, выполнен ли вход, и есть кнопка «Выйти из Instagram». Она полностью удаляет cookie и данные браузера приложения.
- Добавлена политика конфиденциальности (docs/PRIVACY.md).

# Grabbit 1.6.0

- ИИ теперь работает через сервер Grabbit: ключ Gemini больше не хранится внутри приложения.
- Бесплатно до 50 описаний постов в день на устройство. Регистрации нет, используется только анонимный ID устройства.
- Новое в настройках: «Свой ключ Gemini». Ключ хранится в защищённом хранилище телефона, запросы идут напрямую в Google без лимитов.
- Когда лимит исчерпан, приложение показывает понятное сообщение, а пост опишется сам после сброса.
- Поиск по смыслу тоже идёт через сервер.

# Grabbit 1.5.0

- Плавающая нижняя навигация: «Лента», «Доски» и коралловая кнопка добавления по центру. Акцент активной вкладки плавно перемещается.
- Иконка зайца-закладки в шапке, поиск всегда доступен над лентой. Сохранены поиск по смыслу и настройки.
- Новый экран поста: обложка, краткое описание, статусы, доска, теги и заметка. Открытие оригинала и копирование ссылки закреплены внизу.
- Новая панель добавления: ссылка, вставка из буфера, выбор доски и заметка. Ошибки и дубликаты показываются у поля; после сохранения можно открыть пост или добавить следующий.
- Заметка и выбранная доска сохраняются одним SQL-запросом до уведомления очереди. Метаданные и ИИ продолжают обрабатываться в фоне.
- Сохранены редактирование тегов, повторная ИИ-обработка, похожие посты, вход в Instagram, подтверждение удаления и автовозврат после внешнего «Поделиться».
- Новые элементы переведены на английский и украинский. Панели учитывают системную настройку уменьшения движения.
- Браузерная песочница запускается через `npm run web`; новые панели и нижняя навигация общие с Android.

## Выпуск Android

Версия в `app.config.ts`: **1.5.0**, Android `versionCode`: **12**. Пакет остаётся `com.zabolotny.polka`.
Собирать и подписывать APK по существующей инструкции в README с прежним ключом подписи.
Для обновления внутри приложения нужен GitHub Release с APK-ассетом; один коммит исходников обновление не публикует.
Браузерное превью не использует личные данные и не входит в нативную точку входа.

## Проверки перед выпуском

- `npm ci`
- `npx tsc --noEmit`
- `npx tsx --test tests/*.test.ts` — 26 пройдено, 1 пропущен на Node 22.
- Экспорт JS/Hermes-бандла Android и web-бандла через `npx expo export`.
- Проверены в браузере навигация, панель поста, статусы, доски, заметки, добавление, ошибки и дубликаты ссылок, подтверждение сохранения, отмена удаления и обе темы.
- SQLite-тест проверяет, что заметка и доска доступны уже в момент уведомления об изменении данных. На Node 20 эти два теста пропускаются: встроенный SQLite недоступен.
- Физическое Android-устройство/эмулятор и подписанный APK здесь не проверялись. При сборке релиза проверить клавиатуру, системную кнопку «Назад», внешнее «Поделиться», ИИ-очередь и установку поверх 1.4.3.
